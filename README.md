# 🛡️ Anti-Shoulder Surfing System

An AI-based desktop app that detects shoulder surfers using your webcam and alerts you in real-time.

## 🚀 Features
- Live webcam feed
- Detects multiple faces using MediaPipe
- Alerts via popup, sound, or voice
- System tray support
- Event logging
